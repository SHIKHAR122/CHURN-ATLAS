# Churn Atlas

## Project Overview

Churn Atlas is an end-to-end SaaS churn and revenue analytics project designed to investigate subscription retention, recurring revenue, and billing performance.

## Objectives

- Assess and improve data quality using Python.
- Store and analyse relational data using PostgreSQL.
- Investigate subscription churn and revenue patterns using SQL.
- Explore data and preliminary KPIs using Excel.
- Build an interactive Power BI dashboard.
- Translate analytical findings into evidence-based business recommendations.

## Technology Stack

- Excel
- Python (Pandas)
- PostgreSQL
- SQL
- Power BI
- Git and GitHub

## Project Status

Currently in the data organisation and profiling stage.

## Data Sources

The project uses a SaaS subscriptions dataset and its associated cleaning challenge. Dataset attribution, licence details, and redistribution permissions will be documented before publication.

## Repository Structure

- `data/` — Local raw and processed datasets
- `excel/` — Data profiling and preliminary analysis
- `python/` — Data-quality checks, cleaning, and exploratory analysis
- `sql/` — Database schema and analytical queries
- `powerbi/` — Interactive dashboard
- `docs/` — Project documentation and findings
- `screenshots/` — Portfolio visuals

## Important Note

The repository excludes local datasets and sensitive credentials by default. Analytical conclusions will be based on validated results and the limitations of the dataset.
